# Harbor 0.30.0

A console round: easier to read, easier on a phone, and fewer dead ends.

**App Store**
- Screenshots: an app's `presentation.gallery` shows as a strip on its install page; tap one to enlarge it.
- The install page links the project's source code (*Source code on GitHub*) and website.
- *App catalog from …* sits under the App Store title with a refresh icon. Harbor now checks for a newer
  catalog every hour (was 6 hours), and an open App Store loads new apps on its own.
- *Backup places* (and *Your repositories*, when you have any) are their own sections next to *Apps*.

**Settings**
- On a desktop the section list and the section scroll separately.
- On a phone Settings opens as a list; a section opens alone with *‹ Settings* to go back.
- Readable over pictures: cards are nearly solid by default, and the selected section is a solid tint.
- One *Look* picker: Harbor in *Auto*, *Light* or *Dark*, over the *Picture of the day* (or your own
  picture) or flat *Harbor*. The Dusk, Forest and Plain presets are gone.
- Overview starts with the Harbor version, and an *Update* button when a release is out.

**Notifications** bring their own button: *Harbor x.y.z is available* → **Install now**, an app update →
**Update now**, a failed backup → **Back up now**, a drive problem → **Open Storage**, and so on. On a phone
the bell is the *Alerts* tab with the unread count.

**After a restart** Harbor no longer says "log out and log in" before an encrypted install, restore or
encryption: the dialog asks for your password and carries on. In a terminal: `harbor account unlock`.

**HTTPS by itself**: with secure addresses on, a browser that already trusts Harbor's certificate moves
from `http://harbor.local/` to `https://harbor.local/` on its own. To stay on http in one tab, open
`http://harbor.local/?skiphttps` (`?skiphttps=false` undoes it).

**For app authors**
- New optional manifest field `presentation.source` (an https URL, preferably the GitHub repository).
  **Harbor 0.30.0 is the first release that accepts it**, so an app that uses it declares
  `release.minHarbor: "0.30.0"`.
- `pnpm catalog:hash` reads the manifest properly: a one-line list (`gallery: [a.png, b.png]`) no longer
  drops the screenshots from `release.json`.

API: `POST /v1/account/unlock`, `GET /v1/network/https/probe`; `GET /v1/setup` gains `https`; notifications
gain `actions`; new error code `MACHINE_KEY_LOCKED` (409, CLI exit 3) replaces `INVALID_STATE` for a locked
machine key (decision 164).

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.30.0`.
