# Harbor 0.28.3

A one-line fix to 0.28.2.

- `harbor` on the PATH works. 0.28.2 linked `/usr/local/bin/harbor` to `/opt/harbor/bin/harbor`, but the
  launcher looked for its runtime next to the link (`/usr/local/node`) and failed with
  "exec: /usr/local/node/bin/node: not found". Both launchers now follow the link to the real file.
  The full path `/opt/harbor/bin/harbor` worked throughout.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.28.3`.
