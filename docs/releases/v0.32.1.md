# Harbor 0.32.1

Two fixes to 0.32.0.

- **Apps open correctly from Tailscale.** With the console opened at `https://<box>.<tailnet>.ts.net/`, *Open* built
  `https://<box>.<tailnet>.ts.net:38xxx/` — Harbor's home-network address with the tailnet name — and the browser
  refused its certificate (`ERR_CERT_COMMON_NAME_INVALID`). Now an app opens at its own tailnet address when it has one,
  and otherwise at its home-network address (`harbor.local`). The same goes for a console opened by a public domain.
- **An action on a busy app waits its turn.** Starting, stopping or updating an app that is still busy with another
  operation no longer fails with "has an active operation": the review says what it is waiting for and opens by itself
  when that is done. `harbor` on the command line waits the same way.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.32.1`.
