# Harbor 0.37.0

Put many apps on Tailscale at once, or a new app as you install it.

- **Settings → Remote access → Apps on Tailscale.** Every app has a checkbox: ticked = it has an address on your
  tailnet. Tick or untick apps (or **Select all** / **Select none**), then **Review N changes**: the dialog lists the
  apps that get an address and the ones that lose theirs, and says why any app cannot change. **Apply** queues them
  all; each is its own operation in the tray.
- **Install page → Access → Also on Tailscale.** The new app also gets a tailnet address once it runs, without
  becoming its main address. Ticked by default while *Every app on Tailscale* is on (untick it to keep one app off).
  CLI: `harbor install <app> --tailnet` or `--no-tailnet`.
- **Fixed: a review looked like a live address.** The review of a *Publish* showed the address it would create as a
  link, so it was easy to open it (and find nothing) before approving. It is now plain text marked "(once you
  approve)".
- **API.** `tailnet` (boolean, optional) on install plan requests; `asked` on `GET /v1/exposures/tailnet-all`.
