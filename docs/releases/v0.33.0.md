# Harbor 0.33.0

App versions you recognise, apps that keep up with their projects, and automatic updates that back up first.

- **The App Store shows each app's version.** Cards, the app's page and update prompts say *v0.12.0*, not only
  Harbor's package revision; an update reads *v0.11.3 → v0.12.0*. `harbor list` has a VERSION column.
- **The official apps follow their projects' releases.** Every day the catalog looks for newer releases, moves each
  app to the newest one and proves it on a real machine first (install the current version, update it, check it
  stays healthy, install the new one from nothing). Patch and minor releases are published on their own; major
  ones wait for a person to review the upgrade notes. Databases inside an app stay on their major version.
- **Automatic updates back the app up first.** An app with *Update this app automatically* on and backups set up
  gets a fresh backup before Harbor updates it; if that backup fails, the update waits and you are told why. A
  finished automatic update shows in Notifications. A version that failed is not tried again after a restart.

For app authors: `pnpm catalog:upstream` (find and apply newer upstream tags) and `pnpm catalog:smoke` (one app on
a real Docker engine through Harbor's own engine) are new; harbor-apps runs them daily (`updates.yml`, rules in
`updates.json`). No package format change: every Harbor since 0.28.0 reads the updated packages.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.33.0`.
