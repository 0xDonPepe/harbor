# Harbor 0.37.1

A security update for the runtime Harbor ships, and Ubuntu 26.04 as a supported host. Thanks to
[@0xDonPepe](https://github.com/0xDonPepe) for both.

- **Node.js 24.22.1.** Harbor runs on the Node.js it bundles, and 0.37.0 bundled 24.12.0. The October 21 Node.js
  security release fixes TLS certificate hostname-check bypasses (CVE-2026-106069, CVE-2026-105483) and a `dns`
  name truncation (CVE-2026-105482), and stops trusting the compromised eMudhra intermediate CA. Harbor makes HTTPS
  calls (app catalog, image registries, its own updates), so update when you can.
- **Ubuntu 26.04 LTS is supported.** The one-line installer and `harbor bootstrap` accept it. Tailscale now installs
  from the apt suite that matches your system, instead of Ubuntu 24.04's on every host (Debian included).
- **Clearer refusal on other Ubuntu/Debian releases.** An Ubuntu or Debian release Harbor does not support (say
  25.10) is no longer told to retry with `--force` / `HARBOR_FORCE=1`, which could not work. The message names the
  supported releases.

Not tested by us yet: app installs and backups on Ubuntu 26.04 (the contributor's bootstrap run on real hardware is
recorded in `docs/VERIFICATION.md` §3v).

For the app catalog (nothing changes on your box): **app updates are no longer blocked by the version you already
run.** Before an update reaches the App Store, the catalog installs the current version on a test machine, updates it
and checks it stays healthy. Any restart used to count as a failure, including one in the *current* version as it
waited for its database on first start, so Ghost, Etherpad and Pastefy updates could never pass. The current version
may now restart on its way to healthy; the new version must still start with no restarts at all.
