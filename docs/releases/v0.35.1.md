# Harbor 0.35.1

No change to how Harbor works. This release carries what was checked after 0.35.0:

- **The queue, live.** The operation queue (0.35.0) was run on a real machine: installs waiting behind another
  install, a Stop queued while its own app installed, cancelling a waiting install (its name is free again at once),
  a running item refused with a clear reason, and a restart with items waiting (they end cancelled, their apps
  untouched). Five full uninstalls queued at once ran one after another.
- **Upgrades from 0.35.0 are tested.** A Harbor 0.35.0 state folder is now part of the upgrade tests, next to 0.22.1
  and 0.19.1.

New in the app catalog since 0.35.0 (no Harbor update needed): **Plane**, open-source project management.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.35.1`.
