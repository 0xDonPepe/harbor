# Harbor 0.32.0 — security round

The first **signed** Harbor release, and a full security review's fixes (decisions 165–172). It also carries
everything from 0.31.0, which was never published on its own. Update soon if your Harbor is published on the internet.

**Security**

- **The console is never reachable from the internet.** With LAN mode and a public domain both on, anyone online
  could reach the Harbor login by sending `Host: harbor.local` to your router's port 80/443. Harbor now answers its
  LAN names only to devices on your own network (checked live: a public client gets nothing, the box itself still
  does).
- **Signed releases and catalog.** Releases come with `SHA256SUMS.sig` and the app catalog with `catalog.json.sig`.
  The installer, *Update* and catalog downloads refuse anything without a valid signature, and *Update* never
  goes back to an older version (`sudo harbor self-update apply --to <v> --allow-downgrade` does, by hand).
- **Apps no longer see each other's logins.** Over an app's secure address its login cookies are now private to
  that app, and one app's page can no longer post forms to another. New: **HTTPS only** (Settings → Network) makes
  `http://harbor.local/` a redirect and keeps apps off plain http on your network, so that covers everything.
  Tailscale addresses are not covered yet.
- **USB drives can no longer be a way onto the machine** (`nosuid,nodev`; never mounted on top of another drive;
  a disk holding the system is never offered for Format).
- **Recovery words are no longer stored in Harbor's database** (shown once, as before; older copies are removed).
- **Login limits hold under parallel guessing**, and strangers can no longer lock you out of the machine itself.
- **The local certificate can only vouch for this machine and your network.** An older one: Settings → Network →
  *Replace certificate…*, then trust the new one once per device.
- An update that opens a new port asks first; saved notification and backup passwords only go where they went
  before; an open terminal closes when you log out; mail passwords only travel encrypted; SFTP backup places ask
  you to confirm the server's key; wallpaper downloads never reach your home network; linked apps can no longer
  answer for each other's internal service names.

**Other changes**

- **Second copies of an app:** an installed app shows **Open**; apps that allow it offer **Add another copy…**,
  whose page says it is a separate copy and asks for its name.
- Apps open with the console's own scheme (`?skiphttps` keeps apps on http too).
- After Docker restarts, running sealed apps no longer end up "needs attention" (found on a fresh test machine).

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.32.0`.
