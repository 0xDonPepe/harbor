# Harbor 0.34.1

Harbor now checks the NVIDIA driver before it hands the graphics card to an app, and says what to do when the driver
is the problem.

- **Driver checks.** Harbor reads what is on the machine and says one of these, everywhere it already talks about the
  graphics card (the review, the app page, Settings → Overview, `harbor inspect`, `harbor gpu`). The app runs on the
  CPU until the first two are fixed:
  - *the NVIDIA driver is not running*: the card is there but no driver is loaded (before, Harbor said *No graphics
    card found*). Install it with `sudo ubuntu-drivers install`, then restart the machine. When the driver is
    installed but not loaded, Harbor says so and asks for a restart (and points at Secure Boot if that does not help).
    A card handed to a virtual machine (`vfio-pci`) is left alone.
  - *the machine has not restarted since the NVIDIA driver update*: an update installed a newer driver while the old
    one still runs. Restart the machine. An app already on the card stays on it until then (*in use*); restarting
    the app before the reboot moves it to the CPU.
  - *the NVIDIA driver is older than 525*: only a note. The app still gets the card (CUDA 11 images and video
    transcoding work), but apps built on CUDA 12 or newer, like Ollama, cannot use it. Update the driver if the card
    supports it, then restart the machine.
- **The driver version next to the card.** A working card reads *NVIDIA GeForce RTX 3090 (driver 595.99.02, in use)*
  on the app page and in `harbor inspect`, *(driver 595.99.02)* in Settings → Overview, and *(driver 595.99.02, ready
  for apps)* in `harbor gpu` and the plan's GPU line.
  `harbor gpu --json` adds `driverVersion` (running) and `libraryVersion` (installed).

Harbor only checks drivers. It never installs, updates or removes one: they belong to the operating system (kernel
modules, Secure Boot keys, reboots), and the card may also drive the screen. The Operator Guide (*GPU → Drivers*) has
the commands.

For app authors: no change to the package format. `release.minHarbor: "0.34.0"` stays right for the `gpu` permission.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.34.1`.
