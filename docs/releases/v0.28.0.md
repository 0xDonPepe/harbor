## Harbor 0.28.0 — new apps without waiting for Harbor

Everything in the [0.27.1 release](https://github.com/carlosalaniz/harbor/releases/tag/v0.27.1)
still applies. New in this release:

- **The built-in apps have their own home**: [harbor-apps](https://github.com/carlosalaniz/harbor-apps).
  A new app or an app fix there reaches your machine as a signed catalog, usually within 6 hours.
  No Harbor update needed.
- **Check for new apps** at the bottom of the App Store looks right away (`harbor catalog refresh` in
  the CLI; `harbor catalog status` shows which catalog you have).
- **Safe by default.** Harbor only takes a catalog signed with the key built into Harbor, and only one
  newer than what it has. Anything else is ignored and your current catalog stays.
- **Offline is fine.** Each Harbor release still ships the latest catalog, so a machine without internet
  keeps working with the apps it came with.
- An app that needs a newer Harbor shows "needs Harbor x.y.z or newer" instead of failing to install.
- An app you uploaded yourself keeps its id, even if the official catalog later adds one with the same id.

What to expect:

- **Apps with *Update this app automatically* on can now update on any day** a new catalog arrives, not
  only when Harbor updates. Updates still roll back if the new version does not start. Turn it off in the
  app's drawer if you want to choose when.
- To turn catalog downloads off, set `"catalog": { "url": null }` in `/etc/harbor/harbor.json` and
  restart Harbor. The App Store then says "Catalog updates are off".

What not to trust yet:

- This release was tested on the developer machine only (automated suites and a signing test with a
  throwaway key). The first download of a real catalog from GitHub, on a real machine, has not been
  run yet. See [VERIFICATION.md](../VERIFICATION.md) §3q.
- After Harbor restarts, `harbor catalog status` says "Not checked since the daemon started" until the
  next check: the last check time is not saved yet.

Already running Harbor? Settings → Overview → Update.
