# Harbor 0.33.1

- **Update right from the App Store.** An installed app with a newer version waiting now shows *Update available*
  and the versions it moves between (*v3.2.1 → v3.3.1*) on its App Store card and its Store page, with **Update** as
  the main button and *Open* next to it. It opens the same review as the app's own page.

Also in 0.33.0, not listed in its notes: **Every app on Tailscale** (Settings → Remote access, off by default) gives
every app its own tailnet address; see the Operator Guide, "Every app on Tailscale".

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.33.1`.
