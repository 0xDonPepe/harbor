# Harbor 0.30.1

A fix to 0.30.0.

- `http://harbor.local/` now really moves to `https://harbor.local/` in a browser that trusts Harbor's
  certificate. In 0.30.0 the browser marked the trust check as cross-site (the http page asks the https
  address), Harbor's request guard refused it, and the page stayed on http. That one open check is now let
  through; every other API request keeps the guard. `?skiphttps` still keeps a tab on http.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.30.1`.
