# Harbor 0.36.0

A VPN for your apps, and apps that stay offline. Every app now has an **Internet access** choice: *Direct*, *Through
the VPN* or *Offline*. You reach every app exactly as before in all three.

- **Settings → VPN.** Paste (or choose) the WireGuard configuration file your VPN provider gives you (Mullvad, Proton
  VPN, IVPN, AirVPN and most others; pick one server and "all traffic"). Harbor shows whether it is connected, its
  server, tunnel address and DNS. The private key stays on this machine, readable by root only, and is never shown
  again. A file with `PostUp`, `PreUp`, `PostDown`, `PreDown`, `Table`, `FwMark` or `SaveConfig` is refused (Harbor
  never runs commands from it).
- **Through the VPN.** Everything the app opens goes through the VPN, its DNS lookups included, whatever resolver it
  uses. It never falls back to direct: while the VPN is not connected (or none is set up) it has no internet, and the
  bell tells you after 5 minutes. Your own network (a NAS, a printer, the router) stays reachable from it.
- **Offline.** The app opens no connection at all: not the internet, not your network, not this machine, not other
  apps (a Harbor link to another app still works). Like a network permission switched off on a phone.
- **Send every app through the VPN** (Settings → VPN): every app set to Direct goes through it too; offline apps stay
  offline. Harbor restarts each running app that changes, one at a time.
- **Per app:** the app's page → **Internet** → **Change…**, or the install page's **Internet** row. A running app
  restarts for a few seconds when its choice changes; a stopped one changes when it next starts.
- **Packages** may ask for a default (`network.internet: offline | vpn`, first accepted by this release: declare
  `release.minHarbor: "0.36.0"`). Your choice wins and is kept across updates.
- **What stays direct:** Harbor itself (its updates, the app catalog, Tailscale, Let's Encrypt) and image downloads,
  so offline and VPN apps still update.
- **CLI.** `harbor vpn` (status), `harbor vpn set <file> [--name …]`, `harbor vpn every-app on|off`,
  `harbor vpn remove`; `harbor internet <app> [direct|vpn|offline|default]`; `--internet` on `install` and
  `configure`.
- **API.** `GET/PUT/DELETE /v1/vpn`, `PUT /v1/vpn/all-apps`, `POST /v1/vpn/check`; `internet` on plan requests
  (install, configure), on apps, plans and catalog items.
- **Under the hood.** An nftables table of Harbor's own and policy routing on the host (never inside your apps),
  loaded before Docker starts at boot, so no app runs without its rules. Bootstrap installs `nftables` and
  `wireguard-tools`. A machine that never uses any of it is not touched.

Verified live on a real machine with a real WireGuard server: the app leaves with the VPN's address, its lookups go
only through the tunnel, the kill switch holds when the server stops or the VPN is removed, offline apps are refused
everything and still answer, and the boot order keeps the rules ahead of Docker (docs/VERIFICATION.md §3t).
