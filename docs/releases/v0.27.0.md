## Harbor 0.27.0 — a simpler install page

Everything in the [0.26.0 release](https://github.com/carlosalaniz/harbor/releases/tag/v0.26.0)
still applies. New in this release:

- **The install page asks one storage question.** One line says where the whole app will live (this
  machine or a drive), how much free space that place has, and roughly how much room the app needs.
  *Change* shows every place in one list. Photo, media and file apps start out on the plugged-in drive
  with the most free space.
- **Plain words.** "Encrypted — unlocks automatically when you sign in" and "Only you, on this machine"
  replace the explanations about volumes, kernels and 127.0.0.1. *How?* still explains the encryption.
- **Everything that can wait is under Advanced**: instance name, your own passphrase, keeping data in
  a folder of your own (now clearly marked "not encrypted"), versions and the exact path.
- The page says what happens after Install (for example, "you'll create your Immich account").
- Package authors: an optional `presentation.sizeHint` ("About 300 MB, plus your files") appears as
  "Needs …" on the install page.

Already running Harbor? Settings → Overview → Update.
