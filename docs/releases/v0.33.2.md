# Harbor 0.33.2

Two fixes found while packaging new apps.

- **One app can no longer break the others' plain addresses.** An app opened over the secure home-network address
  could tell the browser to use HTTPS for `harbor.local` for a year (Trilium does), and then every
  `http://harbor.local:<port>` app address failed in that browser. Harbor now drops that instruction for apps on the
  shared machine name.
- **ntfy notifications with emoji or non-Latin text are delivered.** A title like *Фото connected* made the delivery
  fail before it left the machine; it now goes out encoded the way ntfy reads it.

Already running Harbor? Settings → Overview → Update, or `sudo /opt/harbor/bin/harbor self-update apply --to 0.33.2`.
