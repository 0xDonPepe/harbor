## Harbor 0.27.1 — install page fixes

Everything in the [0.27.0 release](https://github.com/carlosalaniz/harbor/releases/tag/v0.27.0)
still applies. Fixed after trying 0.27.0 on a real machine:

- **The review step now says the same thing as the install page.** It shows who can reach the app
  (your home network address, not "localhost, this machine only") and where it lives, in plain
  words. The exact path and every step are under *Exactly what Harbor will do*. Reassuring facts are
  no longer shown as amber warnings.
- **A small USB stick no longer becomes the default** for photo and media apps. A drive is chosen
  only when it has more free space than this machine.
- **A domain another app already uses is no longer offered** as an app's main address.
- Sizes use GB and TB everywhere on the install page.
- Keeping data in a folder of your own now says so in the summary ("Encrypted, except …").
- Dialogs and the progress tray no longer let the page behind show through.
- Smaller things: no one-option radio list, plainer drive messages, no empty version.

Already running Harbor? Settings → Overview → Update.
